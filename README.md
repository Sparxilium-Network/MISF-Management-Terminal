# MISF Management Terminal

[GitHub 儲存庫](https://github.com/Sparxilium-Network/MISF-Management-Terminal)

> [!WARNING]
> **本專案仍處於開發階段，請勿用於正式環境。**
> 相關安全保護機制尚未完善。

MISF 是一個桌面程式，用來集中管理多台 Linux／BSD 伺服器的套件更新：透過 SSH 連上主機，檢查有哪些套件可以更新，並在你確認後升級。不需要安裝 Java、瀏覽器或另外架設管理伺服器。

開發、建置與技術細節請見 [開發說明](docs/DEV.md)。

## 下載與啟動

到 GitHub 的 [Releases](https://github.com/Sparxilium-Network/MISF-Management-Terminal/releases) 下載對應的壓縮檔：

- **Windows**：`MISF-Management-Terminal-windows-x86_64.zip`，解壓後執行 `misf.exe`。
- **Linux**：`MISF-Management-Terminal-linux-x86_64.tar.gz`，解壓後執行 `./misf`。需要圖形桌面環境。

目前只有預先發行版（Pre-release）。不需要安裝，解壓即可使用。

## 開始使用

1. 按左側的 **「+ 新增主機」**，填入名稱、位址、連接埠與帳號。
2. 選擇登入方式：密碼、匯入私鑰檔，或使用「SSH 金鑰管理」中已儲存的金鑰。一般帳號可另填 sudo 密碼；留空時會沿用 SSH 密碼。
3. 第一次連線前，按 **「主機指紋」** 核對伺服器指紋並確認。之後指紋若改變，程式會直接阻擋連線，以防連到假冒的主機。
4. 按 **「測試連線」**，程式會自動辨識作業系統與套件管理器，例如「Ubuntu 26.04 · APT」。
5. 按 **「偵測並檢查更新」** 取得可更新的套件清單。檢查不會安裝任何東西。
6. 確認清單後按 **「套件升級…」**，勾選了解風險後執行。結果會列出已升級的套件與仍待更新的套件。

滑鼠停在會連線或使用 sudo 的按鈕上約 1.5 秒，會顯示實際要執行的命令與風險說明。

> [!CAUTION]
> 升級會直接修改遠端系統，無法自動復原；更新核心後需自行重新開機。建議先在一台測試主機上試，也避免同一叢集的所有節點同時升級。

### 支援的系統

| 系統 | 套件管理器 | 支援程度 |
| --- | --- | --- |
| Debian、Ubuntu | APT | 檢查與升級 |
| Fedora、RHEL 8 以上 | DNF | 檢查與升級 |
| CentOS 7 等 | YUM | 檢查與升級 |
| FreeBSD、DragonFly | pkg | 檢查與升級 |
| OpenBSD、NetBSD | — | 只支援連線測試 |

程式會自動偵測套件管理器；若同一台主機裝了多種（例如同時有 DNF 與 YUM），可在「編輯主機」手動指定。

### 一次處理多台主機

切到 **「批次作業」** 分頁，勾選多台主機後一起檢查或升級。每台主機的結果分開保存，一台失敗不影響其他台。同一批只能是同一種套件管理器（在上方切換 APT／DNF／YUM／pkg）。尚未確認指紋或尚未偵測系統的主機無法勾選。

## 整理主機清單

- **分類**：按清單上方的「+ 新增分類」建立分類。
- **拖曳**：把主機拖到其他位置或分類，拖曳分類標題可調整分類順序。搜尋時暫停拖曳。
- **收合**：點分類名稱可收合或展開；在分類標題按右鍵可重新命名或刪除。刪除分類不會刪除主機，主機會移到「未分類」。
- **搜尋**：上方搜尋框可依名稱、位址或備註篩選。

## 設定

點左上角 **「設定」** 開啟設定視窗，按右上角 ✕ 關閉。改動會立即生效並自動儲存。

- **LUKSbox 設定**：啟用加密主機庫、管理解鎖金鑰、匯出加密備份（見下一節）。
- **偏好設定**：
  - 外觀：跟隨系統、淺色或深色。
  - 主機清單顯示：「完整」、「只顯示主機名稱」（一頁能放更多主機），或「自訂顯示項目」，從狀態燈、使用者@位址:連接埠、作業系統版本、備註第一行中挑選要顯示的資訊。
- **語言與文字**：繁體中文（台灣）或 English。
- **關於**：版本、資料庫格式與開發狀態說明。

視窗大小也會記住，下次以相同大小開啟。

## 保護你的主機資料：LUKSbox 加密

主機的位址、帳號、密碼與私鑰預設存在本機資料庫，**未加密**。建議啟用加密：

1. 開啟「設定 → LUKSbox 設定」，按「啟用 LUKSbox 加密…」，設定至少 12 個字元的解鎖密碼。
2. 程式建立加密主機庫並驗證可以解鎖後，會詢問是否刪除原本的明文檔案。
3. 之後每次啟動都要先解鎖；按「鎖定」可隨時鎖上。
4. 在「管理解鎖金鑰」可以新增備援密碼或 **Passkey**（Windows Hello 或 FIDO2 安全金鑰），最多 8 組，每組都能單獨解鎖，也可以命名或撤銷。
5. 按「匯出加密備份…」保存一份備份，並實際試著解鎖一次。

> [!IMPORTANT]
> 遺失所有密碼與 Passkey 就**無法復原**資料。請保留一組可取回的備援密碼。撤銷金鑰或更改金鑰後，請重新匯出備份；舊備份仍可用舊金鑰開啟。

加密只保護「尚未解鎖」的檔案，無法保護已遭入侵的電腦。Passkey 裝置必須支援 PRF／hmac-secret；Windows Hello 需要 Windows 11 22H2 以上。Linux 只支援實體安全金鑰，且每次需輸入金鑰的 PIN。

## 資料存放位置

所有資料都放在使用者目錄下的 `.misf-management` 資料夾，完整路徑顯示在主視窗右上角。

- 主機庫：`hosts.db`（未加密）或 `hosts.lbx`（已加密）。
- 偏好設定：`ui-settings.json`。只存語言、外觀、視窗大小等，不含任何帳密，即使主機庫加密也不會被加密。
- 操作紀錄：`logs/`。記錄你做了哪些操作及結果，只含主機的顯示名稱，不含 IP、帳號、密碼或遠端輸出。紀錄不會自動清理。請勿在主機名稱中填入敏感資訊。
