# RUSTSEC-2023-0071（rsa）處理方式

2026-10-30

- 命中 `rsa 0.10.0-rc.18`；公告沒有已修補版本。
- `russh 0.65.0` 精確要求 `=0.10.0-rc.18`，無法單獨升到已發布的 rc.19；較新的 `rsa` 也不能當作 Marvin Attack 修補。
- 決定：保留 RSA SSH 功能，不加入 audit ignore，不標示已解決。`cargo audit` 因此維持失敗退出碼，不可宣稱整體掃描通過。
- 推論界線：掃描命中不等於已證明 MISF 的 SSH 用戶端簽章流程可被該攻擊利用；也未證明不可利用。
- 待辦條件：russh 放寬 `rsa` 版本且 `rsa` 發布修補版時重新評估。
