# 使用指南

> 最後修改：2026-11-08 ｜ 基於 commit：`2669c10`

本文件說明 MISF 的進階用法。下載、第一次使用與加密主機庫的基本說明見 [README](../README.md)。

## 一次處理多台主機

切到 **「批次作業」** 分頁，勾選多台主機後一起檢查或升級。每台主機的結果分開保存，一台失敗不影響其他台。同一批只能是同一種套件管理器（在上方切換 APT／DNF／YUM／pkg）。

排序在「設定 > 偏好設定 > 批次作業排序」切換：同步左側順序與分類、待更新套件最多優先、最近操作優先，或依主機名稱。選「同步左側順序與分類」時，每個分類有一列標題，勾選標題可一次選取該分類中所有可執行的主機。排序方式會記住。尚未確認指紋或尚未偵測系統的主機無法勾選。

表格會填滿整個寬度。拖曳表頭欄位之間的分隔線可以調整比例（例如把主機名稱拉寬），雙擊分隔線還原預設比例；比例會記住。要顯示哪些欄位（例如使用者、IP／連接埠）在「設定 > 偏好設定 > 批次作業欄位」勾選。

點選主機會在表格下方顯示它的套件清單、已升級套件、執行輸出與連線資訊，可用「上一台／下一台」切換。若把「設定 > 偏好設定 > 批次作業套件明細」改為「雙擊主機開啟視窗」，表格下方就不再顯示，改成雙擊主機名稱開啟視窗；按 Esc、點視窗外或按「關閉」即可關閉。

**分階段延後**：Ubuntu 會分批推送部分更新（phasing），APT 升級時會顯示「Not upgrading yet due to phasing」並暫時不裝。這些套件不是升級失敗，所以升級完成後「待更新套件」仍可能有數字；「分階段延後」欄顯示其中有幾個是這種情況，滑鼠停在數字上可以看到套件名稱。這個數字只在升級後才有，單純檢查時顯示「—」。

## 整理主機清單

- **分類**：按清單上方的「+ 新增分類」建立分類。
- **拖曳**：把主機拖到其他位置或分類，拖曳分類標題可調整分類順序；「未分類」標題也能拖曳，預設排在最後。分類中的主機會縮排顯示。搜尋時暫停拖曳。
- **收合**：點分類名稱（包括「未分類」）可收合或展開；在分類標題按右鍵可重新命名或刪除。刪除分類不會刪除主機，主機會移到「未分類」。
- **搜尋**：上方搜尋框可依名稱、位址或備註篩選。

## 設定

點左上角 **「設定」** 開啟設定視窗，按右上角 ✕ 關閉。改動會立即生效並自動儲存。

- **LUKSbox 設定**：啟用加密主機庫、管理解鎖金鑰、匯出加密備份（見[解鎖金鑰與備份](#解鎖金鑰與備份)）。
- **偏好設定**：
  - 外觀：跟隨系統、淺色或深色。
  - 主機清單密集度：「標準（卡片）」或「緊湊（樹狀單行）」，緊湊模式每台主機只佔一行，詳細資訊接在名稱後面，滑鼠停留可看完整內容。
  - 主機清單顯示：「完整」、「只顯示主機名稱」（一頁能放更多主機），或「自訂顯示項目」，從狀態燈、使用者@位址:連接埠、作業系統版本、備註第一行中挑選要顯示的資訊。
  - 預設解鎖方式：「密碼」、「Windows Hello」或「FIDO2 安全金鑰」。選了 Passkey 時，程式啟動遇到鎖定的主機庫就直接跳出驗證畫面，不必先在解鎖視窗選 Passkey 再按確認（Linux 仍要輸入金鑰 PIN）。驗證畫面上的「改用密碼」可以切回密碼欄位。
- **語言與文字**：繁體中文（台灣）或 English。
- **關於**：版本、資料庫格式與開發狀態說明。

視窗大小也會記住，下次以相同大小開啟。

## 解鎖金鑰與備份

在「設定 → LUKSbox 設定」可以管理解鎖方式與備份。

- **管理解鎖金鑰**：新增備援密碼或 **Passkey**（Windows Hello 或 FIDO2 安全金鑰），最多 8 組，每組都能單獨解鎖，也可以命名或撤銷。新密碼至少 8 個字元，且要包含數字、字母、符號其中至少兩種。
- **匯出加密備份…**：保存一份加密備份後，請實際試著解鎖一次。撤銷或更改金鑰後請重新匯出；舊備份仍可用舊金鑰開啟。
- **鎖定**：隨時鎖上主機庫，之後需重新解鎖。

Passkey 裝置必須支援 PRF／hmac-secret；Windows Hello 需要 Windows 11 22H2 以上。Linux 只支援實體安全金鑰，且每次需輸入金鑰的 PIN。

> [!IMPORTANT]
> 遺失所有密碼與 Passkey 就**無法復原**資料。請保留一組可取回的備援密碼。
