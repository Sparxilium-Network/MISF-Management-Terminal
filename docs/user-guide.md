# 使用指南

> 最後修改：2026-11-18 ｜ 基於 commit：`e48c67f`

> [!WARNING]
> 目前只有 **APT**（Debian／Ubuntu）在真實主機上測試過；DNF、pacman、apk 等其他功能不保證可用或安全。

本文件說明 MISF 的進階用法。下載、第一次使用與加密主機庫的基本說明見 [README](../README.md)。

主機頁上會修改主機的三個操作（套件升級、APT dist-upgrade、重新開機）收在 **「進階操作」** 選單裡；右側的 **「其他操作」** 選單收著主機指紋、重新載入、編輯主機與刪除主機。選單在選了項目或點選單外時關閉。主機頁右上角的卡片顯示待更新套件、延後套件、檢查狀態與上次檢查，下方一行是帳號@位址、系統、套件管理器與登入方式；要顯示哪些可在「設定 > 偏好設定 > 外觀與主機清單」的「主機頁」中勾選。

「套件清單」與「已升級套件」分頁的表格上方有一個放大鏡，按下後才顯示篩選框，可依套件名稱篩選；再按一次放大鏡會清除篩選並收起篩選框。

會修改或讀取遠端主機的按鈕與選單項目（測試連線、檢查、升級、dist-upgrade、重新開機及對應的批次按鈕），滑鼠停留時會顯示將在遠端執行的命令、作用與風險。在這些按鈕與選單項目上按右鍵選「複製將執行的命令」（右鍵選單可按 Esc 或點選單外關閉），可把命令複製到剪貼簿，方便自行核對或在主機上手動執行。複製的是 MISF 實際送出的命令文字；一般帳號的命令含 `sudo -S`，手動執行時會從終端機詢問 sudo 密碼。按鈕停用時無法開啟右鍵選單。

**pacman 與 apk 主機**：

- pacman（Arch Linux）的檢查以 `checkupdates` 在暫存目錄同步一份私有的套件資料庫，不會執行 `pacman -Sy`（Arch 不支援只同步不升級），也不需要 sudo；主機要先安裝 `pacman-contrib` 與 `fakeroot`，否則檢查會失敗並提示。升級執行 `pacman -Syu`，會同步並升級整個系統。
- apk（Alpine Linux）預設只有 doas，doas 無法從標準輸入讀密碼；root 以外的帳號要安裝 sudo。apk 的索引抓不到或簽章不受信任時只會顯示警告，MISF 仍把它當作索引更新失敗。

舊版存下的 BSD 主機、選了 YUM 或偵測為 YUM／pkg 的主機，讀取時會改回 Linux 與「自動偵測」，下次操作重新偵測，主機上沒有支援的套件管理器時會說明。

**sudo 密碼怎麼送出**：一般帳號的命令以 `sudo -S` 執行，sudo 要求密碼時 MISF 才把密碼寫給它，每條命令最多一次。MISF 是看輸出中有沒有一段固定的提示字串來判斷 sudo 在要密碼，所以：

- **root 帳號**的命令不經過 sudo，MISF 不會送出任何密碼；輸出中出現提示字串也不理會。
- **免密碼 sudo（`NOPASSWD`）的帳號**：sudo 不會要密碼，但升級時套件的安裝腳本（已經是 root）若故意印出同樣的提示字串，MISF 會把 sudo 密碼送給它；sudo 密碼欄留空時，以密碼登入的主機會改送 SSH 登入密碼。這類帳號建議改用私鑰登入並把 sudo 密碼欄留空，這樣就沒有密碼可送（此時若輸出中出現提示字串，操作會失敗並說明需要 sudo 密碼；發生在升級途中時，升級會被中止）。

視窗底部的狀態列顯示最近一次操作的結果。點視窗最左側直條上的時鐘圖示，可在頁面下方開啟「過往操作」，由新到舊列出這次執行的結果與錯誤（含時間，針對單一主機的結果會標出主機名稱），再點一次收合。進度訊息不會列入。紀錄只存在記憶體中（最多 200 筆），關閉程式或鎖定主機庫時清除；需要完整紀錄時，請在設定的「LOG」匯出。

### 中斷進行中的操作

檢查、升級、dist-upgrade、批次作業與測試連線進行中，狀態列右側會出現紅色的 **「中斷」**。重新開機不能中斷：命令一送出，重新開機就已排定。

- 中斷會立即斷開這個操作的 SSH 連線，遠端正在執行的命令也會跟著被終止。
- **檢查與測試連線**：按下就中斷，不另外詢問。主機上的套件不會有變動，保留上次的結果。
- **升級與 dist-upgrade（含批次）**：會先跳出確認視窗。中斷升級時，遠端的 apt／dpkg 可能停在半途，之後需要登入主機執行 `sudo dpkg --configure -a` 修復。被中斷的主機會標示為「結果未知」並存檔，重新啟動後仍看得到。
- **批次作業**：已完成的主機結果已經存好；執行中的主機被中斷；還沒開始的主機不會執行。狀態列會列出成功、失敗、執行中被中斷與未執行的台數。
- 中斷和關閉程式一樣有風險，只是不必關掉整個程式。卡住的升級建議先登入主機確認狀態，再決定是否中斷。

操作進行中按標題列的 **「鎖定」**：若操作可以中斷，會詢問要「操作結束後鎖定」或「中斷並鎖定」；其他操作（例如重新開機）都很短，會等它結束後自動鎖定。閒置自動鎖定仍不會中斷操作，見[設定](#設定)。

操作進行中（狀態列顯示「處理中」）關閉主視窗時，會先詢問是否仍要關閉。關閉會立即中斷 SSH 連線：若正在升級，遠端的 apt／dpkg 可能停在半途，需要登入主機執行 `sudo dpkg --configure -a` 修復，建議等操作完成再關閉。批次中已完成的主機結果已經存好。

若背景工作意外結束（程式錯誤），狀態列不會一直卡在「處理中」：會顯示錯誤，正在升級的主機標示為「結果未知」（遠端可能已部分執行，請登入確認），錯誤訊息會列出這些主機的名稱。這個標示會存進主機庫，重新啟動後仍看得到；若存檔失敗，錯誤訊息會說明，請先記下名稱。之後請重新啟動 MISF 再繼續操作。

### 工具列與終端機

主視窗沒有系統標題列，最上方一列就是標題列：左邊是「設定」「鎖定」「SSH 金鑰管理」等命令（像 IDE 的選單列，滑鼠移上去才會反白），右邊是最小化、最大化／還原、關閉。主機庫的加密方式與檔案位置在「設定 › 關於」。拖曳標題列的空白處移動視窗，雙擊最大化或還原；拖曳視窗四邊或四角調整大小。操作進行中按關閉，一樣會先詢問。

視窗最左側有一條細直條，下方三個圖示對應頁面下方的工具視窗：**終端機**、**套件明細**（方塊）與**過往操作**（時鐘）。點圖示開啟，開啟中的圖示呈藍色；再點一次，或按工具視窗右上角的 **－**，即可收合。它們共用頁面下方同一個位置，一次只開一個，高度也共用。

**套件明細**顯示目前選定主機的套件清單、已升級套件、重啟提示、執行輸出與連線資訊，標題是「主機名稱 的套件」。點選另一台主機（側欄或批次表格）時內容跟著換。

檢查、升級、dist-upgrade 或重新開機（單台或批次）開始時，會自動切換到 **「終端機」**，即時顯示 MISF 在遠端執行的命令（以 `$` 開頭的藍色粗體行）與輸出，每台主機一個分頁；分頁前的圓點表示狀態：灰色等待中、藍色執行中、綠色完成、紅色失敗，淡灰色名稱表示批次中斷而未開始。每台主機結束時會加上一行「[完成]」或「[失敗] 原因」。

- 操作的分頁只能看，不能輸入命令。密碼、sudo 密碼與私鑰在顯示前會先遮蔽為「[已隱藏]」。
- 輸出以行為單位顯示，進度列每次重畫（`\r`）都會即時顯示成新的一行；畫面上過寬的行會以「…」省略，完整內容可按 **「複製」**（複製目前分頁的全部文字），或在完成後到結果的「執行輸出」分頁查看。
- 單行超過 8 KiB（約 8,000 字）時，只顯示開頭並標示「（此行過長，已截斷）」，其餘不顯示；結果的「執行輸出」仍保留完整內容。
- 捲到最底時會跟著新輸出捲動；往上捲可停下來閱讀，捲回最底再恢復跟隨。
- 用滑鼠拖曳可選取整行（雙擊選取一行），按 **Ctrl+C** 或右鍵複製選取的行。
- 拖曳工具視窗上緣調整高度，高度會記住。工具視窗開啟時，若上方的主機詳情或批次作業頁放不下，頁面右側會出現捲軸，可捲動查看。還沒執行過任何操作時，終端機會顯示「尚未執行任何檢查、升級或重新開機」。
- 內容保留到下一次檢查、升級或重新開機；每台主機最多保留約 10,000 行，超過時捨棄最舊的部分。測試連線不會顯示在終端機。

### 互動 Shell

在左側選好主機後，按終端機標題列的 **「開啟 Shell」**，會在終端機多一個 **>_ 主機名稱** 分頁，登入該主機並開啟互動 shell。這是完整的終端機模擬：可以使用 `nano`、`top`、`less` 等全螢幕程式、方向鍵、Tab 補全與顏色。

- 點一下畫面即可輸入。
- **選取與複製**：用滑鼠拖曳選取文字，雙擊選取一個字，三擊選取一整行。有選取時按 **Ctrl+C**、**Ctrl+Shift+C** 或右鍵即複製，複製後選取消失。
- **貼上**：**Ctrl+V**、**Ctrl+Shift+V**、**Shift+Insert**，或沒有選取時按右鍵，多行內容保留換行。
- 沒有選取時，Ctrl+C 會照常送給遠端程式中斷執行；Ctrl+X 等其他組合鍵也會送給遠端（例如 nano 的 ^X 離開）。
- **被 MISF 攔下、不會送給遠端的按鍵**：Ctrl+V 與 Ctrl+Shift+V（貼上）、Shift+Insert（貼上）、有選取時的 Ctrl+C 與 Ctrl+Shift+C（複製）。需要把這些按鍵送給遠端程式時（例如 bash 的 ^V 插入下一個字元的原始碼），按標題列「開啟 Shell」右側的 **扳手** 圖示，選「傳送 Ctrl+C（中斷）」、「傳送 Ctrl+V」或「傳送 Shift+Insert」。扳手只在目前分頁是可輸入的 shell 時能按。
- 一般畫面有新輸出、捲動歷史、輸入文字或調整大小時，選取會消失，因為文字可能已經移動；`nano`、`top` 這類全螢幕程式畫面更新時選取會保留。
- 滑鼠滾輪可往回捲動歷史（全螢幕程式執行時沒有歷史）；開始輸入就回到目前畫面。
- 調整工具視窗或主視窗大小時，遠端會收到新的視窗大小。
- **檢查、升級、重新開機等操作進行中，shell 暫停輸入**，畫面下方會說明；操作結束後即可繼續。開啟操作時終端機會切到該操作的分頁，shell 分頁仍保留在後面。
- 在 shell 中輸入 `exit`、按分頁上的 **×**，或鎖定主機庫（包括自動鎖定）都會結束 shell。鎖定時終端機的所有分頁（含操作輸出）都會清除；其他情況下，結束後分頁會保留到你再按一次 ×。
- 有 shell 開著時關閉 MISF 會先詢問，因為 shell 裡仍在執行的程式會被中斷。
- Shell 仍有輸出（例如正在跑的 `apt` 或 `top`）時算有活動，不會自動鎖定；完全沒有輸出也沒有操作時，照設定的時間鎖定。
  - **注意：`top`、`htop`、`tail -f`、`watch` 這類會持續輸出的程式開著時，主機庫永遠不會自動鎖定**，而開著 shell 正是能在主機上執行任何命令的狀態。離開座位前請結束這些程式、關閉 shell，或手動鎖定主機庫。
- 大量輸出（例如 `yes`）時，MISF 會分段處理並讓遠端暫停送出，視窗不會卡住，Ctrl+C 仍可送出。
- Shell 中的操作不會經過 MISF 的確認對話框，也不會記錄你輸入的內容或畫面輸出；稽核紀錄只記「開啟」與「結束」。若在 shell 中更動了套件或設定，MISF 顯示的待更新套件等資訊不會自動更新，請重新檢查該主機。
- 目前不支援在 shell 中使用中文輸入法，也不能以滑鼠選取畫面文字；「複製」會複製整個畫面的文字。

### 容量上限

- **單一遠端命令的輸出**：最多 32 MiB。超過時該命令會被中止並回報錯誤（升級可能因此停在半途），一般升級遠低於此。
- **主機庫**：最多 1024 MiB。每台主機會保存最近一次操作的完整輸出，主機多、輸出大時主機庫會變大；超過上限時無法再儲存，需刪除部分主機。主機庫越大，每次操作（解密、檢查與儲存整個主機庫）越慢，接近上限時每次儲存需數秒，記憶體用量也會明顯增加。

## 一次處理多台主機

切到 **「批次作業」** 分頁，勾選多台主機後一起檢查或升級。每台主機一完成就保存並顯示在表格中，不必等全部結束。某台失敗時會跳出視窗，可選「中斷批次作業」或「繼續其他主機」；決定前不會開始新的主機，已在執行的主機會繼續跑完。中斷後，已在執行的主機也不會被中途停止（可能正在安裝套件），只是不再開始剩下的主機。同一批只能是同一種套件管理器（在上方切換 APT／DNF／pacman／apk）。同時處理幾台主機在「設定 > 偏好設定 > 批次作業」的「同時處理的主機數」調整（1～32 台，預設 8 台），其餘主機排隊，有主機完成才開始下一台。

排序在「設定 > 偏好設定 > 批次作業」的「批次作業排序」切換：同步左側順序與分類、待更新套件最多優先、最近操作優先，或依主機名稱。選「同步左側順序與分類」時，每個分類有一列標題，勾選標題可一次選取該分類中所有可執行的主機。排序方式會記住。尚未確認指紋或尚未偵測系統的主機無法勾選。

表格會填滿整個寬度。拖曳表頭欄位之間的分隔線可以調整比例（例如把主機名稱拉寬），雙擊分隔線還原預設比例；比例會記住。要顯示哪些欄位（例如使用者、IP／連接埠）在「設定 > 偏好設定 > 批次作業」的「批次作業欄位」勾選。

**雙擊主機名稱**會切到「主機詳細資料」分頁並顯示這台主機。在主機名稱上按右鍵有三個選項：

- **前往主機頁面**：同雙擊。
- **在套件明細欄開啟**：選定這台主機，並在下方開啟「套件明細」工具視窗。
- **在視窗中顯示套件明細**：在表格上方開一個視窗，內容相同，另有「上一台／下一台」依表格順序切換；按 Esc、點視窗外或按「關閉」即可關閉。

**分階段延後**：Ubuntu 會分批推送部分更新（phasing），APT 升級時會顯示「Not upgrading yet due to phasing」並暫時不裝。這些套件不是升級失敗，所以升級完成後「待更新套件」仍可能有數字；「分階段延後」欄顯示其中有幾個是這種情況，滑鼠停在數字上可以看到套件名稱。檢查時也會先以模擬升級（不會變更主機）找出這些套件，所以升級前就看得到；同一組更新中依賴這些延後套件、因此也暫時裝不了的套件，也會以上述模擬確認後一併算進來。主機頁右上角卡片的「延後套件」顯示同一個數字，滑鼠停在上面可以看到套件名稱。

## 被保留的套件與 dist-upgrade（只限 APT）

`apt-get upgrade` 不會安裝新套件，也不會移除套件。所以像核心更新這種需要新裝套件的情況（例如 `linux-generic` 要新裝 `linux-image-7.0.0-43-generic`），升級後套件會被「保留」（kept back），待更新數字不會變少。

Ubuntu 分階段推送時，同一組更新中有些套件被延後，依賴它們的套件也會被列為保留。這種套件 dist-upgrade 也不會安裝。MISF 會另外模擬「假設分階段更新都已推送」的 dist-upgrade（只模擬，不會變更主機）：那時就能升級的套件只是在等推送，算進「分階段延後」，不當成被保留，也不會為它們跳出報告。

其他被保留的情況，升級（或整個批次）結束後會跳出 **「需要 dist-upgrade 的主機」** 報告。每台主機一個勾選框，下方一行是模擬 `dist-upgrade` 的摘要：有幾個套件被保留，以及會新安裝、升級和**移除**幾個套件。這個模擬不會變更主機。主機頁也會顯示一行提醒。

- 勾選要執行 dist-upgrade 的主機。模擬沒有列出任何變動的主機預設不勾選：這通常表示 dist-upgrade 也不會升級那些套件（例如 Ubuntu 的分階段推送，或相依問題），也可能是模擬失敗。
- 按 **「詳細情況…」** 會開啟一個獨立視窗，列出每台主機被保留的套件、模擬會新裝／升級／移除的每個套件（含版本），模擬的原始輸出，以及 dist-upgrade 會在遠端執行的命令。報告開著時可以一直參考這個視窗。
- 勾選「我了解…」後按 **「執行 dist-upgrade（N 台）」** 就直接開始，不會再跳出另一個確認視窗；勾選多台時以批次執行。按 **「取消」** 關閉報告。報告只能用這兩個按鈕關閉，按 Esc 或點報告外面都不會關掉。
- dist-upgrade 執行完後不會再跳出報告；若仍有套件被保留，狀態列會列出那些主機，原因請看執行輸出。

也可以用主機頁「進階操作」選單中的「APT dist-upgrade…」、批次作業頁的「批次 dist-upgrade」按鈕。dist-upgrade 可能移除套件或安裝新核心，請先看清楚會移除哪些套件再執行。

## 重啟提示與重新開機（只限 APT）

APT 主機每次檢查或升級完成後，MISF 會另外讀取主機的重啟狀態（一般帳號會透過 sudo 讀取，和升級相同）：

- **需要重新開機**：例如新核心已安裝但還沒載入時，會顯示目前核心與預期核心，以及要求重新開機的套件。
- **需要重啟的服務**：還在使用舊版函式庫的服務、容器與使用者工作階段。主機要安裝 needrestart 才看得到；沒安裝時只會顯示是否需要重新開機。

有需要處理的項目時，主機頁會出現一行警示，詳細內容在結果卡片的 **「重啟提示」** 分頁；批次作業表格也有「重啟提示」欄。

MISF 升級時**不會自動重啟任何服務**，需要重啟的服務請自行在主機上處理。

**重新開機**：主機頁「進階操作」選單中的「重新開機…」只對已確認指紋的 APT 主機開放，需要兩次確認：先勾選了解風險，再確認主機名稱與位址。送出後主機會在 **1 分鐘後** 重新開機，期間可在主機上執行 `shutdown -c` 取消。

## 整理主機清單

- **新增主機或分類**：按「主機清單」右側的 **+**，再選「新增主機」或「新增分類」。
- **拖曳**：把主機拖到其他位置或分類，拖曳分類標題可調整分類順序；「未分類」標題也能拖曳，預設排在最後。分類中的主機會縮排顯示。搜尋時暫停拖曳。
- **收合**：點分類名稱（包括「未分類」）可收合或展開；在分類標題按右鍵可重新命名或刪除。刪除分類不會刪除主機，主機會移到「未分類」。
- **搜尋**：上方搜尋框可依名稱、位址或備註篩選。

## 設定

點左上角 **「設定」** 開啟設定視窗；它是獨立的視窗，可以移到旁邊或另一個螢幕，大小會記住，按視窗的 ✕ 或再點一次「設定」關閉。關閉主視窗時設定視窗會一起關閉。左側是分類樹，「偏好設定」底下再分成幾頁，點「偏好設定」可以收合或展開；右側標題顯示目前位置（例如「偏好設定 › 安全性」），每頁的設定再以分隔線分成幾個區段。改動會立即生效並自動儲存。

- **LUKSbox 設定**：管理解鎖金鑰、匯出加密備份（見[解鎖金鑰與備份](#解鎖金鑰與備份)）。
- **偏好設定**：
  - **外觀與主機清單**：
    - 外觀：跟隨系統、淺色或深色。
    - 字型：Noto Sans TC（預設，內嵌於程式）、Noto Sans TC 粗體（所有文字都用粗體，螢幕上字太細時使用），或系統字型（作業系統的預設介面字型）。
    - 主機清單密集度：「標準（卡片）」或「緊湊（樹狀單行）」，緊湊模式每台主機只佔一行，詳細資訊接在名稱後面，滑鼠停留可看完整內容。
    - 主機清單顯示：「完整」、「只顯示主機名稱」（一頁能放更多主機），或「自訂顯示項目」，從狀態燈、使用者@位址:連接埠、作業系統版本、備註第一行中挑選要顯示的資訊。
    - 主機頁：勾選右上角卡片要顯示的項目（待更新套件、延後套件、檢查狀態、上次檢查）與其下方的連線資訊行；四個項目都不勾時不顯示卡片。
  - **安全性**：
    - 預設解鎖方式：「密碼」或「FIDO2 安全金鑰」。選了安全金鑰時，程式啟動遇到鎖定的主機庫就直接跳出驗證畫面，不必先在解鎖視窗選 Passkey 再按確認（Linux 仍要輸入金鑰 PIN）。驗證畫面上的「改用密碼」可以切回密碼欄位。
    - 自動鎖定：「永不自動鎖定」或「閒置後鎖定」（預設，15 分鐘），後者可設定 1～1440 分鐘。以前選過「永不自動鎖定」的設定不會改變。主機庫解鎖時，超過設定時間沒有滑鼠或鍵盤操作就自動鎖定，畫面上的主機資料與終端機內容立即清除。檢查、升級等作業執行中不會鎖定，作業結束後才重新計時；互動 shell 有輸出時也算有活動。鎖定會關閉尚未儲存的主機編輯視窗，並結束所有互動 shell。
  - **批次作業**：批次作業排序、套件明細位置、要顯示的欄位，以及「重設欄寬」。
- **語言與文字**：繁體中文（台灣）或 English。
- **LOG**：本次執行的完整紀錄，只存在記憶體，關閉程式後就消失。按「匯出 LOG…」可存成文字檔。每次操作有一段以 `********` 框起的標題（例如「使用者 進行批次 APT 升級（3 台）」），每台主機一個區塊，從主機名稱到「END OF 主機名稱」，內含主機 ID、帳號與位址、指紋、套件變動和遠端原始輸出。匯出的檔案**含敏感資訊且未加密**；只有密碼、sudo 密碼、私鑰、私鑰密語、解鎖密碼與 PIN 會被遮蔽，分享前請先檢查。主機庫鎖定時無法匯出（鎖定不會清除這份紀錄，解鎖後仍可匯出）。
- **關於**：版本、資料庫格式、主機庫的加密方式與檔案位置，以及開發狀態說明。

視窗大小也會記住，下次以相同大小開啟。

## 解鎖金鑰與備份

在「設定 → LUKSbox 設定」可以管理解鎖方式與備份。

- **管理解鎖金鑰**：新增備援密碼或 **Passkey**（FIDO2 安全金鑰），最多 8 組，每組都能單獨解鎖，也可以命名或撤銷。新密碼至少 8 個字元，且要包含數字、字母、符號其中至少兩種。撤銷最後一組密碼時會特別警告：之後只剩 Passkey，遺失或損壞安全金鑰就再也打不開主機庫。
- **匯出加密備份…**：保存一份加密備份後，請實際試著解鎖一次。撤銷或更改金鑰後請重新匯出；舊備份仍可用舊金鑰開啟。
- **鎖定**：隨時鎖上主機庫，之後需重新解鎖。

Passkey 只支援實體 FIDO2 安全金鑰（不支援 Windows Hello），裝置必須支援 PRF／hmac-secret。Linux 每次需輸入金鑰的 PIN；Windows 由系統視窗要求 PIN 或觸碰。

> [!IMPORTANT]
> 遺失所有密碼與 Passkey 就**無法復原**資料。請保留一組可取回的備援密碼。
