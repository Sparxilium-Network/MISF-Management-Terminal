# 使用指南

> 最後修改：2026-11-14 ｜ 基於 commit：`65542ce`

> [!WARNING]
> 目前只有 **APT**（Debian／Ubuntu）在真實主機上測試過；DNF、YUM、pkg 等其他功能不保證可用或安全。

本文件說明 MISF 的進階用法。下載、第一次使用與加密主機庫的基本說明見 [README](../README.md)。

主機頁上會修改主機的三個操作（套件升級、APT dist-upgrade、重新開機）收在 **「進階操作」** 選單裡；選單在選了項目或點選單外時關閉。

會修改或讀取遠端主機的按鈕與選單項目（測試連線、檢查、升級、dist-upgrade、重新開機及對應的批次按鈕），滑鼠停留時會顯示將在遠端執行的命令、作用與風險。在這些按鈕與選單項目上按右鍵選「複製將執行的命令」（右鍵選單可按 Esc 或點選單外關閉），可把命令複製到剪貼簿，方便自行核對或在主機上手動執行。複製的是 MISF 實際送出的命令文字；一般帳號的命令含 `sudo -S`，手動執行時會從終端機詢問 sudo 密碼。按鈕停用時無法開啟右鍵選單。

視窗底部的狀態列顯示最近一次操作的結果。點狀態列（或左側的 **>**）可展開「過往操作」，由新到舊列出這次執行的結果與錯誤（含時間，針對單一主機的結果會標出主機名稱），再點一次收合。進度訊息不會列入。紀錄只存在記憶體中（最多 200 筆），關閉程式或鎖定主機庫時清除；需要完整紀錄時，請在設定的「LOG」匯出。

操作進行中（狀態列顯示「處理中」）關閉主視窗時，會先詢問是否仍要關閉。關閉會立即中斷 SSH 連線：若正在升級，遠端的 apt／dpkg 可能停在半途，需要登入主機執行 `sudo dpkg --configure -a` 修復，建議等操作完成再關閉。批次中已完成的主機結果已經存好。

若背景工作意外結束（程式錯誤），狀態列不會一直卡在「處理中」：會顯示錯誤，正在升級的主機標示為「結果未知」（遠端可能已部分執行，請登入確認）。之後請重新啟動 MISF 再繼續操作。

### 容量上限

- **單一遠端命令的輸出**：最多 32 MiB。超過時該命令會被中止並回報錯誤（升級可能因此停在半途），一般升級遠低於此。
- **主機庫**：最多 1024 MiB。每台主機會保存最近一次操作的完整輸出，主機多、輸出大時主機庫會變大；超過上限時無法再儲存，需刪除部分主機。主機庫越大，每次操作（解密、檢查與儲存整個主機庫）越慢，接近上限時每次儲存需數秒，記憶體用量也會明顯增加。

## 一次處理多台主機

切到 **「批次作業」** 分頁，勾選多台主機後一起檢查或升級。每台主機一完成就保存並顯示在表格中，不必等全部結束。某台失敗時會跳出視窗，可選「中斷批次作業」或「繼續其他主機」；決定前不會開始新的主機，已在執行的主機會繼續跑完。中斷後，已在執行的主機也不會被中途停止（可能正在安裝套件），只是不再開始剩下的主機。同一批只能是同一種套件管理器（在上方切換 APT／DNF／YUM／pkg）。

排序在「設定 > 偏好設定 > 批次作業」的「批次作業排序」切換：同步左側順序與分類、待更新套件最多優先、最近操作優先，或依主機名稱。選「同步左側順序與分類」時，每個分類有一列標題，勾選標題可一次選取該分類中所有可執行的主機。排序方式會記住。尚未確認指紋或尚未偵測系統的主機無法勾選。

表格會填滿整個寬度。拖曳表頭欄位之間的分隔線可以調整比例（例如把主機名稱拉寬），雙擊分隔線還原預設比例；比例會記住。要顯示哪些欄位（例如使用者、IP／連接埠）在「設定 > 偏好設定 > 批次作業」的「批次作業欄位」勾選。

點選主機會在表格下方顯示它的套件清單、已升級套件、執行輸出與連線資訊，可用「上一台／下一台」切換。**雙擊主機名稱**會切到「主機詳細資料」分頁並顯示這台主機；在主機名稱上按右鍵也可以選「前往主機頁面」。若把「設定 > 偏好設定 > 批次作業」的「批次作業套件明細」改為「按右鍵主機開啟視窗」，表格下方就不再顯示，改成在主機名稱上按右鍵選「顯示套件明細」開啟視窗；按 Esc、點視窗外或按「關閉」即可關閉。

**分階段延後**：Ubuntu 會分批推送部分更新（phasing），APT 升級時會顯示「Not upgrading yet due to phasing」並暫時不裝。這些套件不是升級失敗，所以升級完成後「待更新套件」仍可能有數字；「分階段延後」欄顯示其中有幾個是這種情況，滑鼠停在數字上可以看到套件名稱。檢查時也會先以模擬升級（不會變更主機）找出這些套件，所以升級前就看得到；主機頁也會顯示一行提示。

## 被保留的套件與 dist-upgrade（只限 APT）

`apt-get upgrade` 不會安裝新套件，也不會移除套件。所以像核心更新這種需要新裝套件的情況（例如 `linux-generic` 要新裝 `linux-image-7.0.0-43-generic`），升級後套件會被「保留」（kept back），待更新數字不會變少。

發生這種情況時，升級（或整個批次）結束後會跳出 **「需要 dist-upgrade 的主機」** 報告：列出每台主機被保留的套件，以及模擬 `dist-upgrade` 會新安裝、升級和**移除**哪些套件。這個模擬不會變更主機。主機頁也會顯示一行提醒。

要處理時，可以在報告中按「對這些主機執行 dist-upgrade…」，或用主機頁「進階操作」選單中的「APT dist-upgrade…」、批次作業頁的「批次 dist-upgrade」按鈕。dist-upgrade 可能移除套件或安裝新核心，確認視窗會列出上次模擬中會被移除的套件，請先看清楚再執行。

## 重啟提示與重新開機（只限 APT）

APT 主機每次檢查或升級完成後，MISF 會另外讀取主機的重啟狀態（一般帳號會透過 sudo 讀取，和升級相同）：

- **需要重新開機**：例如新核心已安裝但還沒載入時，會顯示目前核心與預期核心，以及要求重新開機的套件。
- **需要重啟的服務**：還在使用舊版函式庫的服務、容器與使用者工作階段。主機要安裝 needrestart 才看得到；沒安裝時只會顯示是否需要重新開機。

有需要處理的項目時，主機頁會出現一行警示，詳細內容在結果卡片的 **「重啟提示」** 分頁；批次作業表格也有「重啟提示」欄。

MISF 升級時**不會自動重啟任何服務**，需要重啟的服務請自行在主機上處理。

**重新開機**：主機頁「進階操作」選單中的「重新開機…」只對已確認指紋的 APT 主機開放，需要兩次確認：先勾選了解風險，再確認主機名稱與位址。送出後主機會在 **1 分鐘後** 重新開機，期間可在主機上執行 `shutdown -c` 取消。

## 整理主機清單

- **分類**：按清單上方的「+ 新增分類」建立分類。
- **拖曳**：把主機拖到其他位置或分類，拖曳分類標題可調整分類順序；「未分類」標題也能拖曳，預設排在最後。分類中的主機會縮排顯示。搜尋時暫停拖曳。
- **收合**：點分類名稱（包括「未分類」）可收合或展開；在分類標題按右鍵可重新命名或刪除。刪除分類不會刪除主機，主機會移到「未分類」。
- **搜尋**：上方搜尋框可依名稱、位址或備註篩選。

## 設定

點左上角 **「設定」** 開啟設定視窗；它是獨立的視窗，可以移到旁邊或另一個螢幕，大小會記住，按視窗的 ✕ 或再點一次「設定」關閉。關閉主視窗時設定視窗會一起關閉。左側是分類樹，「偏好設定」底下再分成幾頁，點「偏好設定」可以收合或展開；右側標題顯示目前位置（例如「偏好設定 › 安全性」），每頁的設定再以分隔線分成幾個區段。改動會立即生效並自動儲存。

- **LUKSbox 設定**：管理解鎖金鑰、匯出加密備份（見[解鎖金鑰與備份](#解鎖金鑰與備份)）。
- **偏好設定**：
  - **外觀與主機清單**：
    - 外觀：跟隨系統、淺色或深色。
    - 字型：Noto Sans TC（預設，內嵌於程式）、Noto Sans TC 粗體（所有文字都用粗體，螢幕上字太細時使用），或系統字型（作業系統的預設介面字型）。
    - 主機清單密集度：「標準（卡片）」或「緊湊（樹狀單行）」，緊湊模式每台主機只佔一行，詳細資訊接在名稱後面，滑鼠停留可看完整內容。
    - 主機清單顯示：「完整」、「只顯示主機名稱」（一頁能放更多主機），或「自訂顯示項目」，從狀態燈、使用者@位址:連接埠、作業系統版本、備註第一行中挑選要顯示的資訊。
  - **安全性**：
    - 預設解鎖方式：「密碼」、「Windows Hello」或「FIDO2 安全金鑰」。選了 Passkey 時，程式啟動遇到鎖定的主機庫就直接跳出驗證畫面，不必先在解鎖視窗選 Passkey 再按確認（Linux 仍要輸入金鑰 PIN）。驗證畫面上的「改用密碼」可以切回密碼欄位。
    - 自動鎖定：「永不自動鎖定」（預設）或「閒置後鎖定」，後者可設定 1～1440 分鐘。主機庫解鎖時，超過設定時間沒有滑鼠或鍵盤操作就自動鎖定，畫面上的主機資料立即清除。檢查、升級等作業執行中不會鎖定，作業結束後才重新計時。鎖定會關閉尚未儲存的主機編輯視窗。
  - **批次作業**：批次作業排序、套件明細位置、要顯示的欄位，以及「重設欄寬」。
- **語言與文字**：繁體中文（台灣）或 English。
- **LOG**：本次執行的完整紀錄，只存在記憶體，關閉程式後就消失。按「匯出 LOG…」可存成文字檔。每次操作有一段以 `********` 框起的標題（例如「使用者 進行批次 APT 升級（3 台）」），每台主機一個區塊，從主機名稱到「END OF 主機名稱」，內含主機 ID、帳號與位址、指紋、套件變動和遠端原始輸出。匯出的檔案**含敏感資訊且未加密**；只有密碼、sudo 密碼、私鑰、私鑰密語、解鎖密碼與 PIN 會被遮蔽，分享前請先檢查。
- **關於**：版本、資料庫格式與開發狀態說明。

視窗大小也會記住，下次以相同大小開啟。

## 解鎖金鑰與備份

在「設定 → LUKSbox 設定」可以管理解鎖方式與備份。

- **管理解鎖金鑰**：新增備援密碼或 **Passkey**（Windows Hello 或 FIDO2 安全金鑰），最多 8 組，每組都能單獨解鎖，也可以命名或撤銷。新密碼至少 8 個字元，且要包含數字、字母、符號其中至少兩種。撤銷最後一組密碼時會特別警告：之後只剩 Passkey，重灌系統、換電腦或遺失安全金鑰就再也打不開主機庫。
- **匯出加密備份…**：保存一份加密備份後，請實際試著解鎖一次。撤銷或更改金鑰後請重新匯出；舊備份仍可用舊金鑰開啟。
- **鎖定**：隨時鎖上主機庫，之後需重新解鎖。

Passkey 裝置必須支援 PRF／hmac-secret；Windows Hello 需要 Windows 11 22H2 以上。Linux 只支援實體安全金鑰，且每次需輸入金鑰的 PIN。

> [!IMPORTANT]
> 遺失所有密碼與 Passkey 就**無法復原**資料。請保留一組可取回的備援密碼。
